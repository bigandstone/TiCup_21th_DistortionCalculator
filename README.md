# 信号失真度测量仪 — STM32

综合电路设计课程 A 题，基于 STM32 测量输入信号的**总谐波失真度 (THD)**，与 2021 年 TI 杯信号题要求相似。

## 硬件

| 部件 | 说明 |
|------|------|
| 主控 | STM32G431 (Cortex-M4F, 含 DSP 指令集 + FPU) |
| ADC | TIM 触发 + DMA 搬运，多通道同步采样 |
| 显示 | TFT LCD |
| 调试 | UART 串口打印波形/频谱 |

## 工作原理

```
模拟信号输入 → ADC (TIM+DMA) → FFT 运算 (CMSIS-DSP) → 谐波提取 → THD 计算 → LCD/串口显示
```

## 功能

1. **数据采集**：TIM 定时触发 ADC，DMA 自动将数据搬运到缓冲区
2. **FFT 频谱分析**：调用 CMSIS-DSP 库的 FFT 函数，提取基波和各次谐波分量
3. **THD 计算**：`THD = √(∑ 谐波有效值²) / 基波有效值 × 100%`
4. **波形显示**：LCD 显示时域波形、归一化幅值频谱、THD 值
5. **串口输出**：打印输入波形数据和频谱图，用于调试分析

用 Keil MDK 打开 `MDK-ARM` 目录下的项目文件编译下载。
